# End-to-End-Sales-Analytics-Pipeline-using-Azure-and-PySpark
Built an end-to-end Sales Analytics pipeline on Azure using Databricks + PySpark and Delta Lake. Raw sales files land in Azure Data Lake Storage [ADLS], flow through bronze → silver → gold transformations, and publish curated tables and Key Performance Indicators [KPI] for Business Intelligence [BI]. I automated runs with Azure Data Factory [ADF]/Databricks Jobs, added data quality checks, and tuned Delta tables for fast, cost-aware dashboards.

Tech: Azure Databricks, PySpark, Delta Lake, ADLS Gen2, ADF, Synapse Serverless SQL [Structured Query Language],Tableau.
